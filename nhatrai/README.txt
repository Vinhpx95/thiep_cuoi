THIỆP MỜI NHÀ TRAI · XUÂN VINH & THANH HẰNG
===========================================

Cấu trúc:
  index.html        Trang thiệp
  css/style.css     Giao diện
  js/config.js      THÔNG TIN THIỆP (tên, ngày giờ, địa chỉ, tài khoản...) – chỉ cần sửa file này
  js/main.js        Hiệu ứng & chức năng (không cần sửa)
  assets/images/    Ảnh cưới
  assets/audio/     Nhạc nền (background.mp3 – thay file cùng tên để đổi bài)

Xem thử: mở index.html bằng trình duyệt (Chrome/Edge).

Đưa lên web miễn phí (chọn 1):
  - Netlify Drop: vào app.netlify.com/drop, kéo thả cả thư mục "nhatrai".
  - Vercel: cài Vercel CLI, chạy "vercel" trong thư mục này.
  - GitHub Pages: tạo repo, tải toàn bộ file lên, bật Pages.

Gửi đích danh khách: thêm tên vào cuối link, dùng dấu gạch nối thay khoảng trắng.
  Ví dụ: https://ten-mien-cua-ban/#Anh-Tuấn
