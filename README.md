# Thiệp cưới online · Xuân Vinh & Thanh Hằng

Thiệp mời nhà trai. Cấu trúc:

- `index.html` – trang thiệp
- `css/style.css` – giao diện
- `js/config.js` – **thông tin thiệp** (tên, ngày giờ, địa chỉ, tài khoản…) – chỉ cần sửa file này
- `js/main.js` – hiệu ứng & chức năng
- `assets/audio/` – nhạc nền, `assets/images/` – ảnh cưới

Xem trên GitHub Pages: `https://vinhpx95.github.io/thiep_cuoi/`

Gửi đích danh khách: thêm tên vào cuối link, ví dụ `https://vinhpx95.github.io/thiep_cuoi/#Anh-Tuấn`.

Xem thử trên máy: mở `index.html` bằng Chrome/Edge.
